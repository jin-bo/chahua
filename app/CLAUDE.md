## 聊天界面渲染（P10）

- **mermaid 只在 message_end 全文到位时渲一次**，流式 delta 期间禁调（半截抛 parse error 闪烁）；失败保留原 `<pre>` + `.mermaid-error`。
- **mermaid SVG 走手工 sanitize，不能换 DOMPurify**（DOMPurify 强制清空 `<foreignObject>`，mermaid v11 label 会被剥光）；安全靠 mermaid 自带 sanitize + CSP + 手工剥 `on*`/`javascript:` 三层兜底。
- **挂件按 rel 去重**（防 live+history 双触发）；图片预览懒拉不 eager 内嵌（占位 `<img>` 后发 `download_file purpose=preview` 回包灌字节），SVG 走 pill 不内嵌；**切房 / clear 必 `clearPendingArtifactPreviews()`**（否则等待中的 `<img>` 已被摘走无处灌）。
- **P10.1 数学/化学走 marked「转义前封箱」+ KaTeX live-DOM 延后渲**：行内扩展把整段 `$…$`/`$$…$$` 作单一 token 收走成 carrier span（否则 CommonMark 反斜杠转义先吃掉 `\,`/`\\`）；只认 `$`/`$$`，货币歧义 pandoc 风格收窄。
- **KaTeX 在 DOMPurify 之后、只 message_end 调一次、逐公式独立 render**；`trust:false` + `throwOnError:false` + **不传 `macros`**（`\gdef` 不跨公式泄漏）。
- **highlight.js v11 喂转义 textContent、单块单次、跳 mermaid/已高亮/未注册语言**；懒加载走 `@highlightjs/cdn-assets` ESM（**不能用 `highlight.js` 包的 CJS shim**，沙箱渲染进程无 CJS 互操作）。
- **`enhanceContent` = mermaid + highlight + math 单钩子**（各自幂等），挂 `renderGuestText` / `endStreamingMessage` 注入点；流式 `appendDelta` 不调。P10.1 纯前端零后端改、不 bump `schema_version`、CSP 不改；打包须保 `katex/dist/fonts/`。
- **`task_panel.js` goal 那处 `enhanceContent` 调用不可达 —— 富渲染只在茶客气泡里发生**。`createTaskPanel` 唯一调用点（`renderer.js:700`）必传 `onPatchTask` ⇒ goal 恒走 plaintext contenteditable 分支，`renderMarkdown + enhanceContent` 的 else 分支从未执行。**别再把它写进注入点清单**（P10.1 与 P10.2 初稿各错一次）；要补通须先设计「展示态 ↔ 编辑态」切换，contenteditable 会和有状态渲染产物打架。

## flint 数据图表渲染（P10.2）

完整设计与实测数字见 [`docs/P10.2-flint 数据图表渲染.md`](../docs/P10.2-flint%20数据图表渲染.md)、溯源见 `docs/INVARIANTS.md §9.x P10.2`，改不变量两处同步。

- **flint 图表纯前端渲染：载体 `pre>code.language-flint`、后端零改、不 bump `schema_version`、CLI 不渲染**。图规格与数据整体内联在那段 markdown 里，渲染只在渲染进程；transcript / envelope / 导出一律留 honest 源码。`enhanceContent` = mermaid + highlight + math + **flint**（四者区域不相交、各自幂等、均 fire-and-forget）；流式 `appendDelta` 仍不调。`highlightCode` 显式跳 `language-flint`。**用户气泡 / 系统气泡不渲染**（前者走 `textContent`、后者不调编排器）。
- **flint 安全/资源边界 = 入口白名单 + 拒 `data.url` + 生成式编译 + 键域出口断言 + `svg`/`richText` + 三条资源闸 + 钉版 + 失败保留源码**。出口断言**按键域不按值域**（合法数据里就有 URL 串）、**不含 `target`**（Sankey/Graph 的节点名）、`renderItem` 必须是函数；`graphic` 走**类型白名单 + 递归 children**（flint 对 ordinal size 通道会自造 `{type:"group", children:[…]}` 图例，只放行 `text` 会把一张合法散点图整张否掉）；**不得扩写成通用 ECharts option 消毒器**。截断闸认的是**丢数据的 code 清单** `{overflow, too-many-groups-pyramid}`，**不能改成按 severity 拦**（`invalid-option-value` 同为 warning 却不丢数据，拦它会给出错误的修法指引）；升级钉版时有一条用例断言 dist 里 code 全集未变，逼一次人工分诊。`replaceWith` 必须是整条链的**最后一步**（先在离树 `<figure>` 上 `init`+`setOption`，渲染期抛错当场 `dispose`）——反过来做会静默空白。`assertNoSilentTruncation` 必须排在剥 `_` 私有键**之前**。三档徽标文案不可合并（修法不同：减行数 / 减类别数 / 改规格）。
- **按气泡宽重编译，且收窄档须同时满足「落进栏」与「绘图区 ≥ 160 px」；都不满足用自然尺寸 + 横向滚动**。尺寸交还给 flint（`chart_spec.canvasSize` 重编译），**绝不**编译完再改画布（flint 把 `legend.left`/`grid` 烤成绝对像素）。渲染前先给气泡加 `.has-flint`**再量宽**，量的是待替换 `<pre>` 的边框盒宽（不量 `.bubble`，含 padding）**再扣掉 `<figure>` 自己的 18px chrome**（padding+border，不扣则「落进栏」恒偏松、右边缘刻度被裁）。`.has-flint` 必须是 `max-width:92%` **加 `flex-grow:1`**：`.bubble` 是不 grow 的 flex item，只写 max-width 时气泡宽度由 `<pre>` 里最长那行 JSON 决定（实测栏里空着 750px 却只量到 434px），放宽等于没做。失败 / LRU 退回源码后要**撤掉** `.has-flint`（判据是气泡里还有没有活图）。硬地板客观存在（`Pie Chart` ≥ 280 px），**横向滚动是常规分支不是异常分支**。
- **绘图区口径认全 `grid` 三形态，且收窄不得引入 base 没有的 `overflow`**。`grid` 是**对象**（笛卡尔）/ **数组**（`column`/`row` 分面，每分面一个）/ **缺失**（非笛卡尔）三种；只认对象会让下限对**所有分面图恒过**。分面取 `min(grid[].width)`。收窄本身会制造 flint 的 overflow 截断，故候选一旦引入 base 没有的 `overflow` 就停止收窄退回 base——否则一张完好的图会被自家收窄循环判成「数据被截断」，还叫作者去减类别。
- **flint + ECharts 是第一个有状态渲染器：视口门 + 两道回收**。首次编译由 `IntersectionObserver` 门住（`rootMargin:200px`），且 observer **懒创建**、**root 必须是真滚动容器 `#messages`**（`rootMargin` 按规范只扩隐式 root 的矩形，留 null 时那 200px 提前量对聊天列表完全无效）。回收两道缺一不可：① `sweepFlintCharts()` 在每次 `enhanceFlint` 开头、**早退之前**调；② **`resetFlintCharts()` 挂 `renderSidebar`**，紧挨既有 `clearPendingArtifactPreviews()`——只有 ① 的话，切到空房 / 纯用户消息房（用户气泡走 `textContent`、不经 `enhanceContent`）清扫**一次都不会跑**。待渲 `<pre>` 也要登记并在卸载时 `unobserve`；淘汰时必须 `unobserve` 那个 `<figure>`。软上限 12 的 LRU **回退成源码**（自愈）而非拒渲；全部可见时不淘汰；**新图登记时直接标为可见**，否则会被自己淘汰成循环。
- **「渲染器必须拒什么」与「作者应该怎么写」是两张清单，不得互相冒充**。渲染端**真闸子**只有：顶层五键 / 拒 `data.url` / `≤1000` 行 / 画布上界——作者侧 skill 里这四项的阈值必须逐条一致。「对象数组 + 标量单元格」是**作者建议**，`sanitizeFlintInput` **不查**（不是安全面：单元格值全程无字符串→DOM 解析）。**已知缺口明记**：嵌套对象 / 嵌套数组单元格不抛错、产出非空但错误的 series、绕过空 series 守门 → 静默错图；可选加固写在 `flint_core.mjs` 的注释里，`flint_core.test.mjs` 有一条**故意断言现状**的用例——开了加固它会变红，那是提醒同步改文档，不是删用例。
- **纯逻辑住 `flint_core.mjs`（`.mjs` 非 `.js`），且测试必须挂在 `uv run pytest` 上**。`app/package.json` 无 `"type":"module"` 且**不能加**（`main` 是 CJS 主进程）⇒ `renderer/*.js` 在 Node 眼里是 CJS，`.js` 直接 import 在 Node 18 上是 SyntaxError，而本机 Node 22.7+ 的语法探测会假绿。本仓**无 CI、无既有 JS 测试**，故 `flint_core.test.mjs` 由 `tests/test_frontend_flint.py` subprocess 带起来——**有 node 却缺 `app/node_modules` 时 fail 而不是 skip**（`uv sync` 从不装它，静默 skip 会让整套用例在一片绿里消失）。编译链本身也住 `flint_core.mjs`（`compileFlintOption`），**两边共用同一份**：测试里手抄一份副本的话，删掉产品里的形态守门或调换断言顺序，用例照样全绿。**沙箱渲染进程里的真加载只有真 Electron 能证**（P10.1 在 highlight.js 的 CJS shim 上栽过）——`npm run smoke:flint` 是那道门，与主窗口同 `webPreferences`、与 `index.html` 同一份 CSP。
- **flint 主题两半：文字与五档轴走 `init` 第二参、序列色板按位替换**。flint 把 cat10 硬编码进产物 ⇒ 主题里写 `color` 无效；映射表从 `opt.color` 自身现造（覆盖 cat10/cat20/变体）；只碰颜色键（不可能碰到数据文本）；**语义色图型（`Waterfall Chart`）整张跳过**；五档轴必须齐（漏档的轴退回原厂灰黑，用一张类别轴柱图验不出来）。**升级钉版必须重跑**：`flint_core.test.mjs` 的自包含性用例 + 37 图型扫描 + 语义色 grep。
