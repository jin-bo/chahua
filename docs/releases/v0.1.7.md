# v0.1.7 —— 桌面登录态注入凭证（P15）+ 聊天富渲染（P10.1）+ 系统 prompt 英文化（P14）（2026-06-17）

继 v0.1.6「多模态图像输入」之后第八个版本。本版三条主线：**P15 桌面登录态自动注入 LLM 凭证**（用户在桌面壳里选模型 / 填 key 即时生效、零重启、纯 env 热重建、绝不写 toml / 不落盘 / 不进日志）、**P10.1 聊天富渲染**（数学公式 / 化学表达式 / 代码高亮在渲染进程渲成富呈现，承 P10 mermaid 同骨架、纯前端后端零改）、**P14 系统 prompt 全量英文化 + 精练 + 发言前回顾历史**（省 token + 对齐指令，用户内容不动、输出语言随对话）。外加附件标记换 `<attachment>` 格式、桌面 UI 资产打磨（附件 pill / 文件类型角标 / 空房 hero / app 图标）、`requires-python` 降到 3.11、两处纯重构。1479 测试全过（v0.1.6 收线 1431 → +48），3.12 / 3.11 双解释器同绿。

## 亮点

- **桌面选模型即时生效、零重启**：新增 `set_llm_credentials{provider, model, base_url?, api_key}` inbound（前台房专用、严格白名单），只改 `os.environ` → `_cancel_and_drain_all_foreground` + `_replace_session` 内存热重建。**纯 env、绝不写 toml**（靠房间默认 LLM 两层 fallback 的 `try_from_env()` 接管，显式 `[room.llm]` 天然优先）；粒度只动「房间默认」锚点，靠 fallback 的 `[scoring]` / `[summary]` / 茶客随新默认一起换。
- **凭证绝不泄漏三个面（盘 / envelope / 日志）**：raw key 只入进程内存 environ；下发前端只有 `api_key_env` 名 + `api_key_ready` bool。日志面也堵死 —— `api_key` 走 `require_str(redact=True)`（失败只 log 字段名 + 类型）、`base_url` 进日志前经 `_redact_base_url` 剥到 `scheme://host`（防 userinfo / `?token=` 第二凭证载体）。改 env 前快照旧值，写 env + 重建包 `try/finally`，失败 / 异常都逐个回滚（全内存无磁盘 IO）+ 保留旧 session。
- **气泡里的公式 / 化学 / 代码渲成富呈现**：数学 `$E=mc^2$` / `$$\int_0^1 x\,dx$$`、化学 `$\ce{2H2 + O2 -> 2H2O}$`、` ```python ` 代码块在 Electron 渲染进程渲成排版公式 / 反应式 / 暗底高亮。**后端零改、不动 `schema_version`、CLI 不渲染、CSP 不改**。
- **富渲染安全靠结构而非黑名单**：数学走 marked 行内扩展「转义前封箱」成 carrier（避开 CommonMark 反斜杠转义吃掉 `\,`），KaTeX 延后在 **DOMPurify 之后**的 live DOM 上**逐公式独立** render；`KATEX_OPTS` 硬编码 `trust:false`（禁 `\href` / `\includegraphics` / `\html*`）+ `throwOnError:false`（语法错退错误色源码）+ **不传 `macros`**（`\gdef` 连气泡内都不跨公式泄漏）。代码高亮 highlight.js v11 喂转义 `textContent`、单块单次、跳 mermaid / 已高亮 / 未注册语言。
- **系统 prompt 英文化但输出语言不变**：英文化「系统生成、喂 LLM」的文案省 token；塑造茶客回复的块统一带 `Always reply in the same language as the conversation (default: Chinese).` 锚点，防英文指令隐性带偏输出语言。`_speak_instruction_block` 加 recall 段落（发言前回顾自身 tool 结果、仅截断才回 source 重读）。
