# v0.1.11 —— flint 数据图表渲染（P10.2）+ MTS 预算收尾轮（P8.7）（2026-08-04）

继 v0.1.10「消息回溯与历史搜索（P18）+ 依赖大修」之后第十二个版本。两条线各自独立、都不动 wire：**主线 P10.2** 把茶客回复里的 ` ```flint ` 围栏块画成图表，是气泡里第四类富渲染（前三类是 mermaid / 公式化学 / 代码高亮），**纯前端、后端零改**；**另一条 P8.7** 让托管任务会话撞预算终结时留下一份交接，而不是「托管中 · 剩余 N 轮」那条 bar 悄无声息地消失，**不新增任何回合**。两者都不 bump `schema_version`、不改前端 wire 协议。1576 测试全过，另有 node 层 45 条与真 Electron 冒烟 21 项。

## 亮点

- **茶客能画图了**：回复里的 ` ```flint ` 块（[flint](https://github.com/microsoft/flint-chart) 语义图表规格 JSON）在渲染进程编译成 ECharts option 并渲成 SVG，覆盖 37 种图型（柱 / 线 / 散点 / 饼 / 热力 / 桑基 / 甘特 / 分面…）。**图规格与数据整体内联在那段 markdown 里**——transcript / envelope / 导出的 markdown / CLI 一律仍是 honest 源码，渲染只发生在渲染进程。
- **安全边界整体沿观澜 P4.20，注入面比 mermaid 更小**：入口白名单 + 拒 `data.url` + 生成式编译 + **键域**出口断言 + `renderer:'svg'` + `tooltip.renderMode:'richText'` + 三条资源闸 + 钉版 + 失败保留源码。flint 产物**完全不经 `innerHTML`**，没有任何字符串→DOM 的解析步骤；块内容永远是文本、只经 `JSON.parse`，而 JSON 里没有函数 —— ECharts 的 `formatter` / `renderItem` 回调注入面在这条链上天然不存在（这正是选 flint 而非「让模型直接写 ECharts option」的理由）。
- **按气泡宽重编译 + 绘图区下限（茶话室独有）**：聊天气泡比观澜的 wiki 栏窄约 40%，照抄上游「取第一个 `_width ≤ 栏宽` 的档」会把绘图区压到 81 px。故收窄档须**同时**满足「落进栏」与「绘图区 ≥ 160 px」，都不满足就用自然尺寸 + 横向滚动 —— 硬地板客观存在（`Pie Chart` 恒 ≥ 280 px），**横向滚动是常规分支不是异常分支**。尺寸交还给 flint 重编译（`chart_spec.canvasSize`），绝不编译完再改画布。
- **视口门 + 两道实例回收（茶话室独有）**：flint + ECharts 是茶话室**第一个有状态渲染器**，而 `renderSidebar` 每帧 `room_info` 都整列表重建 + 全量重放 transcript。`IntersectionObserver` 门住首次编译；回收兼用 `enhanceFlint` 内的脱树清扫**与** `renderSidebar` 里的 `resetFlintCharts()`（只有前者的话，切到空房 / 纯用户消息房清扫一次都不会跑），另有软上限 12 的 LRU **回退成源码**（自愈、可重渲，不是拒渲）。
- **配套作者侧 skill**：mermaid / LaTeX 模型本就会写，**flint 是新规格语言、模型不会自发产出合法块** —— 没有作者侧供给，渲染器就是「通了电没有灯」。`flint-chart-author` 从 agentao 引进到 `examples/personas/Maya/skills/`，其自校验清单里的四条阈值与渲染端逐条一致。
- **MTS 撞预算时给交接，而不是静默消失（P8.7）**：托管会话因 `budget_exhausted` 终结时，用户拿到「做完了什么 / 还剩什么 / 卡在哪 / 一个明确下一步」。**不新增任何回合** —— MTS 的最后一次管理者复查本来就跑在 `budget == 0` 上，它天然是终局回合，只需把那一轮注入的 `<managed_session>` **换成**收尾块，管理者回合总数与改前逐字一致。只给 `budget_exhausted` 收尾（`user_stopped` / `user_cancel` / `task_closed` / `cap_reached` 都不给 —— 「停」就是停）。

## 依赖

- **npm 新增两个直接依赖，均钉版无 `^`**：`flint-chart@0.4.1` + `echarts@6.1.0`（与观澜 P4.20 钉同一份，两仓行为一致）。两者都是**自包含浏览器 ESM**，无 bare import / 无 `require(` / 无 `process.` —— 这条由 `flint_core.test.mjs` 里一条常驻用例机械断言，**升级钉版必跑**（另有 37 图型不误杀扫描与语义色 grep）。
- **Python 依赖零变化**：`agentao>=0.4.18` 不变，`uv.lock` 仅版本号自包更新。
- **打包 bundle 里的 agentao 与开发环境有偏斜（一贯如此，此处记明）**：`build-python-bundle.js` 把本地 `../agentao` **源码**非 editable 装进 bundle，故 dmg 里是 `0.4.20.dev0`（内容 = 已发布的 **0.4.19** + 开发周期版本号 bump，`../agentao` 在 `v0.4.19` 之后只有那一个 chore 提交）；而 `uv.lock` / dev venv / 本版 1576 条测试跑的是 PyPI **0.4.18**。两者都满足 `>=0.4.18`。0.4.19 是纯修正版本，其中 **shell hardline 越权绕过**（`timeout 5 rm -rf /` 一类 wrapper 形态可绕过高于一切 mode preset 与用户规则的底线）与 **MCP `tools/list` 分页丢失第 2 页起的工具**两条对桌面包尤其有意义。
- **本版 `FORCE=1` 是必须的，不是保险起见**：`build-python-bundle.js` 在 `finalPyExe` 已存在且非 FORCE 时**直接 return**，而 bundle 是把 chahua 源码 pip 非 editable 装进去的 —— 不 FORCE 会把上一版的 python 打进 dmg，**P8.7 整个不在包里**。打包后已核 bundle 内 `chahua.__version__ == "0.1.11"`。

## ⚠️ 升级注意

- **升级 `flint-chart` / `echarts` 钉版时有三道必跑的门**：`flint_core.test.mjs` 的自包含性用例（证 dist 仍可在沙箱渲染进程里裸 `import`）、37 图型不误杀扫描（「不该拒的不乱拒」只能靠把全集跑一遍）、以及一条断言 flint dist 里**截断 code 全集未变**的用例 —— 后者会在上游新增 code 时强制一次人工分诊，因为截断闸认的是「丢数据的 code 清单」而非 severity。
- **改主窗口 `webPreferences` 或 `renderer/index.html` 的 CSP 时须一并改 `app/scripts/flint-smoke/`**：那两处「逐字同款」是冒烟有意义的前提，否则冒烟绿而真 app 红。
