# v0.1.0 —— 首次公开发布（2026-05-14）

茶话室的第一个可对外分享的版本。CLI + Electron 桌面壳跑通；macOS 可出 .dmg；三茶客「黄河路」默认房随包带。

## 亮点

- **多 Agent 群聊**：用户 + 多个 [agentao](https://github.com/jin-bo/agentao) 茶客在同一房间对话，可 `@`、可旁听、茶客之间可接话。
- **意愿打分调度**：房间来新消息后，对空闲茶客并发跑轻量 LLM 打分，取分数 ≥ 阈值前 1~2 名以完整 `Agentao.chat()` 发言；没人过阈值就等用户。
- **桌面壳**：Electron 拉 Python sidecar，本地 WebSocket；流式打字机 + markdown 渲染 + 气泡复制；茶客侧栏（头像 / 权限 V 标 / 打分徽章 / @ 补全）；可切房 / 清空 / 停止当前 turn / 断线退避重连。
- **持久化**：每房间一份 `transcript.jsonl`（公开记录）/ `summary.jsonl`（onboarding 摘要）/ `cursor.json`（喂养游标）；茶客私有 memory.db / sessions 落到 `rooms/<room>/guests/<name>/.agentao/`。
- **macOS 打包**：`npm run build:mac` 出未签名 `.dmg`（~130MB，内嵌 python + chahua + agentao）。Windows .exe 接缝（platform 分支 / sidecar resolver / stdin EOF graceful shutdown / build.win 配置）已就位，剩 Windows 主机 / CI matrix 端跑。

## 里程碑（按提交序）

- **P0 骨架**：包布局 + pyproject + Room transcript + TeaGuest 包 Agentao + cli.py。
- **P1 调度**：意愿打分 + @ 路由 + onboarding + 三茶客 + top-1~2 抢话 + want_threshold 0.45。
- **P1.5 房间配置**：`chahua --room <dir>` 读 `room.toml`（最小版）。
- **P2.1 持久化**：transcript / summary / cursor 落盘 + 续聊。
- **P2.2 事件 envelope**：ChahuaTransport + turn/message 生命周期。
- **P2.3 WebSocket server**：本地 ws + 房间装配抽到 `session.py`。
- **P3.1 Electron**：拉 sidecar + 极简消息流。
- **P3.2.1 → P3.2.3**：打字机 + 打分徽章 / 茶客侧栏 + @ 补全 / ws 重连退避；rooms 加「黄河路」+ 宝总 / 汪小姐 / 范总 人格 + 头像 + 权限 V 标；气泡布局（茶客左 / 用户右）+ 进 Room 显示历史。
- **P3.3.1 停止按钮**：cancel turn 协议 + 同按钮形变；sidebar 加切房 / 清空 / @broadcast；后续修 pick None 卡死。
- **P3.3.2 macOS 发布**：
  - **.a / .b** 拆 `app_root` / `user_data_root`；茶客气泡 markdown + DOMPurify + 复制按钮。
  - **.c** electron-builder 打 macOS .dmg + 内嵌 python（build-python-bundle 烤 python + chahua + agentao 进 `app/python-bundle/`，~130MB，idempotent）。
  - **.d** stdin EOF 替 SIGINT 当跨平台 graceful shutdown 信号。
  - **.e** sidecar stderr/stdout 落盘到 `~/Library/Logs/chahua/`。
  - 首启动从 `app/templates/` seed 默认房 / `.env.example` / `USER.md` 到 userData（dev 走仓库根；packaged 走 `~/Library/Application Support/chahua/` + `.chahua-seeded` marker）。
