# v0.1.13 —— 茶客调用看得见、模型协议接得上（P20 / P20.1 / P21 + Agentao 0.5.18）（2026-10-31）

继 v0.1.12「Agentao 0.5.3 升级 + 安装包构建来源可信（P19）」之后第十四个版本。v0.1.12 是地基版，本版把地基上新长出来的东西接到用户面前：**调试抽屉第一次看得见每次模型调用花了多少 token、命中多少缓存、重试了几次**；**茶客在退避重试或整理上下文时不再像卡死**；**`.env` 里写的协议格式终于生效**——新一代 OpenAI 模型不再每句 400，Claude 可以打开提示缓存。另修一个老问题：上游调用失败时，报错文本会被当成茶客发言写进聊天记录。不 bump 任何 `schema_version`，旧房间数据直接可用。测试 1582 → 1665 条全过，另有真实 LLM（OpenAI / Anthropic / Gemini）与桌面壳实测。

## 亮点

- **P21 协议格式与提示缓存**。此前 chahua 只给 agentao 传 key / base_url / model / temperature，`.env` 里的 `*_API_FORMAT` 被静默忽略，一律走 Chat Completions：
  - `gpt-6-astra` 这类模型带工具只能走 `/v1/responses`，在 chahua 里**每次发言 400**；
  - Claude 退到 Anthropic 的 OpenAI 兼容层，且不打缓存断点，每轮 1.3 万输入 token 全价。

  现在每段 LLM 配置多了两个端点属性：**协议**（`api_format`：`openai-completions` 默认 / `anthropic-messages` / `openai-responses`）与**提示缓存**（`prompt_cache`：`anthropic` / 关）。env 按服务商前缀写（`CLAUDE_API_FORMAT` / `CLAUDE_PROMPT_CACHE`），`room.toml` 四类 LLM 段与设置界面四个表单都能配。实测同一茶客第二轮：OpenAI 输入 7,731 其中缓存读 7,656；Claude 打开缓存后 13,347 其中缓存读 13,257（不开为 0）。
- **上游调用失败不再当发言**。agentao 遇 provider 报错不抛异常，而是把 `[LLM API error: …]` 当本轮文本返回；chahua 此前原样写进 transcript，下一轮其他茶客还会读到它。现按出错收尾（气泡显示「出错」），不进聊天记录。
- **P20 茶客调用消耗取证**。调试抽屉每条茶客消息下新增「模型调用（N）」：逐次显示用时、首字延迟、输入（其中缓存读）、输出（其中推理）、结束原因、重试与上下文压缩；turn 头部加「本轮茶客调用」合计。口径刻意保守：计量单位是一次主循环模型调用（含内部重试），不是 HTTP 请求；只统计茶客（打分 / 摘要 / 后台 run 不计）；缓存 / 推理按「其中」显示、不重复相加；上游没报的显示「未提供」而不是 0；不换算费用。
- **P20.1 茶客实时状态提示**。茶客遇到限流 / 5xx 退避重试时，气泡显示「正在重连…（第 n/m 次）」（悬停看原因），做上下文压缩时显示「正在整理上下文…」，状态结束即消失——此前这两种情况只有一个不动的光标，可能长达几十秒。

## ⚠️ 升级注意

- **想让 Claude 用原生协议 + 提示缓存**：在 `~/.env`（或 `<user_data>/.env`）写

  ```
  CLAUDE_API_FORMAT=anthropic-messages
  CLAUDE_PROMPT_CACHE=anthropic
  ```

  `CLAUDE_*` 只在 `LLM_PROVIDER=claude` 时用于房间默认；某个房间或茶客单独用 Claude 时，在设置界面该段选「Anthropic Messages」并勾「Anthropic 提示缓存」。缓存默认关：只有端点认 `cache_control` 才能开（官方 `api.anthropic.com` 实测支持；转发网关不认可能 400）。
- **新一代 OpenAI 模型带工具**：写 `OPENAI_API_FORMAT=openai-responses`。
- **协议与缓存按配置段各管各的**：`room.toml` 某段没写就用默认，不会回退读 env，也不继承别的段。agentao CLI 的全局 `LLM_PROMPT_CACHE` **不读**（切换服务商后会残留到别的端点）。
- **调试抽屉里旧消息没有「模型调用」**：P20 之前的记录不带调用数据，抽屉显示「部分消息无记录」，不算错误。
