# 实验室标准方法校对

## 工作流程

### 第一步：提取标准信息

读取用户指定文档，提取所有标准条目。每条记录：
- 标准编号（含年号），如 `GA/T 756-2021`
- 标准中文名称
- 标准英文名称（如有）

**注意**：文档可能同时含中英文两个版本的标准列表，须分别提取并对应。

---

### 第二步：校验编号格式

参见 `references/standard-number-formats.md` 了解完整格式规则。

快速检查要点：
- 前缀字母全部**大写**（`GB`/`GA`/`SF` 等）
- 类型符 `/T`、`/Z` **大写**，斜杠为**半角** `/`（不能是 `∕` 全角斜杠）
- 前缀与编号之间**恰好一个半角空格**（`GA/T 756`，不能是 `GA/T756`）
- 编号与年号之间**半角连字符** `-`，两侧**无空格**（`756-2021`，不能是 `756—2021` 全角破折号）
- 年号为 **4 位数字**

发现格式问题：立即标注 🔴，给出正确写法：
```
🔴 格式错误：GA∕T756—2021 → 正确格式：GA/T 756-2021
```

---

### 第三步：联网查询 std.samr.gov.cn

对每个标准编号，按以下步骤执行：

**3a. 构造搜索 URL（不含年号）**
```
https://std.samr.gov.cn/search/stdPage?q=<URL编码后的标准前缀+编号>&tid=
```
编码规则：`/` → `%2F`，空格 → `%20`

示例：
- `GA/T 756` → `https://std.samr.gov.cn/search/stdPage?q=GA%2FT%20756&tid=`
- `GB/T 29360` → `https://std.samr.gov.cn/search/stdPage?q=GB%2FT%2029360&tid=`
- `SF/T 0157` → `https://std.samr.gov.cn/search/stdPage?q=SF%2FT%200157&tid=`

**3b. 解析搜索结果**

从页面提取匹配标准的编号、年号、中文名称，以及标准详细页面链接。

若无结果：
1. 提示"⚠️ 标准编号可能有误，未检索到相关标准"
2. 用标准名称中 2~3 个关键词重新搜索
3. 仍无结果 → 标记"🔴 严重：标准不存在或编号错误"

**3c. 获取详细信息**

访问标准详情页，提取：
- 正式中文名称
- 正式英文名称
- 现行年号及状态（现行 / 作废 / 即将实施）

优先取**状态为"现行"的最新版**。

---

### 第四步：校对并输出报告

对每条标准逐一判断（优先级从高到低）：

| 问题类型 | 标记 | 提示语 |
|---------|------|-------|
| 标准不存在 | 🔴 严重 | 标准编号或名称可能出错，未检索到任何匹配记录 |
| 编号格式错误 | 🔴 严重 | 格式错误：`原文` → 正确格式：`正确` |
| 中/英文名称完全不符 | 🔴 严重 | 标准编号或名称可能出错，官方名称为"…" |
| 年号非最新版 | ⚠️ 警告 | 该标准最新年号为 XXXX，文档中使用的 XXXX 版本仍现行 |
| 年号已作废/错误 | ⚠️ 警告 | 标准正确年号为 XXXX（文档所用年号已作废） |
| 名称有文字差错 | ⚠️ 警告 | 文字差错，正确的应该是"…" |
| 全部正确 | ✅ 通过 | — |

---

## 输出报告格式

```markdown
# 标准方法校对报告

**文档**: <文档名称>
**校对时间**: <日期>

---

## 校对汇总

| 序号 | 标准编号 | 年号 | 中文名称 | 英文名称 | 状态 |
|-----|---------|------|---------|---------|------|
| 1 | GA/T 756-2021 | 2021 | 法庭科学 文书鉴定术语 | Forensic sciences--Terminology for document examination | ✅ |
| 2 | GB/T 9360-2023 | 2023 | ... | ... | 🔴 编号错误 |

---

## 🔴 严重问题（N 个）

### 1. 标准编号错误：GB/T 9360-2023
- **文档内容**: `GB/T 9360-2023`
- **问题**: 编号错误，无此标准
- **正确编号**: `GB/T 29360-2023`（法庭科学 电子数据恢复检验规程）

---

## ⚠️ 警告问题（N 个）

### 1. 年号非最新版：GA/T 1474-2018
- **文档内容**: `GA/T 1474-2018`
- **最新版**: `GA/T 1474-2024`（如有）
- **建议**: 确认是否需要引用最新版

---

## 📊 校对统计

| 项目 | 数量 |
|-----|------|
| 提取标准总数 | N |
| 🔴 严重问题 | N |
| ⚠️ 警告问题 | N |
| ✅ 通过 | N |
```

## 注意事项

- 英文名称比对时允许轻微表述差异，但关键术语须一致
- 若文档含中英文对照，两侧编号须完全一致，否则标记为严重错误
- 若无法访问网站，注明"无法联网核查"并基于已知信息判断
- 同一标准编号若有多个年号版本，优先报告最新现行版
