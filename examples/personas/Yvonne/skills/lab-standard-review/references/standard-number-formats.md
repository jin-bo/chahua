# 标准编号格式规则

## 格式模板

```
前缀/类型 编号-年号
```

示例：`GA/T 756-2021`、`GB/T 29360-2023`、`SF/T 0157-2023`

---

## 格式规则详解

| 项目 | 规则 | 正确示例 | 错误示例 |
|-----|------|---------|---------|
| 前缀字母 | 全部大写 | `GB`、`GA`、`SF` | `Gb`、`ga`、`sf` |
| 类型符斜杠 | 半角 `/`（ASCII 0x2F） | `GA/T` | `GA∕T`（全角）、`GA／T` |
| 类型字母 | 大写 | `/T`、`/Z` | `/t`、`/z` |
| 前缀与编号间隔 | **一个**半角空格 | `GA/T 756` | `GA/T756`（无空格）、`GA/T  756`（两空格） |
| 编号与年号连字符 | 半角连字符 `-`（ASCII 0x2D） | `756-2021` | `756—2021`（全角破折号）、`756－2021`（全角减号） |
| 连字符两侧 | 无空格 | `756-2021` | `756 - 2021` |
| 年号 | 4 位数字 | `2021`、`2023` | `21`、`2k21` |

## 常见错误类型

### 1. 大小写错误
```
错：ga/t 756-2021
正：GA/T 756-2021
```

### 2. 全角符号混入
```
错：GA∕T 756—2021   （全角斜杠 + 全角破折号）
错：GB／T 29360－2023（全角斜杠 + 全角减号）
正：GA/T 756-2021
正：GB/T 29360-2023
```

### 3. 空格缺失或多余
```
错：GA/T756-2021    （前缀与编号无空格）
错：GA/T  756-2021  （两个空格）
正：GA/T 756-2021
```

### 4. 年号格式错误
```
错：GA/T 756-21     （两位年号）
正：GA/T 756-2021
```

### 5. 编号数字错误（截断）
```
错：GB/T 9360-2023  （缺少前导位，应为 29360）
正：GB/T 29360-2023
```

## std.samr.gov.cn 查询说明

**搜索 URL 构造**：去掉年号，对前缀+编号进行 URL 编码，末尾加 `&tid=`

| 标准编号 | 搜索 URL |
|---------|---------|
| `GA/T 756-2021` | `https://std.samr.gov.cn/search/stdPage?q=GA%2FT%20756&tid=` |
| `GB/T 29360-2023` | `https://std.samr.gov.cn/search/stdPage?q=GB%2FT%2029360&tid=` |
| `SF/T 0157-2023` | `https://std.samr.gov.cn/search/stdPage?q=SF%2FT%200157&tid=` |
| `ISO 27001` | `https://std.samr.gov.cn/search/stdPage?q=ISO%2027001&tid=` |

**URL 编码规则**：
- `/` → `%2F`
- ` `（空格）→ `%20`

**标准状态字段**（从详情页读取）：
- 现行（有效）
- 废止（已被新版替代，显示替代标准号）
- 即将实施

**年号判断逻辑**：
- 搜索结果包含多个年号 → 取"现行"状态的最新年号
- 文档年号 < 最新现行年号 → 警告（可能有更新版）
- 文档年号对应标准状态为"废止" → 警告（年号已作废）
